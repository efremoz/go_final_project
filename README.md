# Дипломный проект
Написания веб-сервера, который реализует функциональность планировщика задач — это аналог TODO-листа. 

## Цель дипломного проекта
Закрепления навыков по написанию веб-сервера, работе с REST API и базами данных.

**Из заданий со * реализованы:** поиск задач по тексту или дате.

Приложение доступно по адресу: http://localhost:7540

Чтобы протестировать поиск, присвойте переменной Search значение `true` в файле `tests/settings.go`

# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.
